# Example Java Spring Boot Application that is in-secure

### Prerequisite

1. mvn and java are installed locally

## How to run

1. Run `mvn install` this will compile the application
2. cd into the target folder
3. run `java -jar java -jar demo-0.0.1-SNAPSHOT.jar`
    - This will launch the API and can be accessed here: http://localhost:8080

**Note:** The `build_and_run.sh` can also be used to compile and run the application
